# Public repository scope

This repository is the public KM Systems project overview. Keep changes focused on public documentation and approved branding.

Do not upload application source, customer records, credentials, provider tokens, private keys, database exports, deployment configuration, backups or internal release evidence. Those are maintained privately. A public overview does not imply permission to publish them.

Describe implemented features, demonstrations and planned work accurately. Do not present provider coverage or customer pilots as complete without evidence. Preserve the owner-approved KM Systems artwork if branding is added.
